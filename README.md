# Site JA Indústria

## Como abrir no VS Code

1. No VS Code: **File › Open Folder…** e escolha esta pasta (`site-ja`).
2. Quando aparecer o aviso de extensões recomendadas, clique em **Install** (é o *Live Server*).
3. Clique com o botão direito em `index.html` › **Open with Live Server**.
   O site abre no navegador e atualiza sozinho a cada alteração salva.

## Como continuar com o Claude Code

Abra o painel do Claude Code no VS Code e peça normalmente, por exemplo:

> Crie a seção de produtos abaixo da seção Resultados, seguindo esta referência (cole a imagem).

O arquivo `CLAUDE.md` explica para o Claude as cores, fontes e padrões do site.

## Como colocar no ar

Por ser um site estático, basta enviar a pasta inteira para uma hospedagem
(Netlify, Vercel, Hostinger ou a hospedagem atual da empresa) e apontar o domínio.
